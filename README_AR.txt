تقسيم الكتاب إلى JSON منفصل لكل باب

محتويات المجلد:
- index.json: فهرس الأبواب وأسماء الملفات ومساراتها.
- introduction.json: المقدمة وكل النص الذي يسبق الباب الأول.
- chapters/chapter-01.json إلى chapters/chapter-36.json: ملف مستقل لكل باب.

بنية ملف الباب:
- title: عنوان الباب للاستخدام في الفهرس.
- chapter_number: رقم الباب.
- content: نص الباب الأصلي كاملًا، ويتضمن سطر عنوان الباب نفسه، مع الحفاظ على ترتيب النص وفواصل الأسطر الأصلية.

مهم: في HTML يمكن تحميل index.json أولًا ثم قراءة ملف الباب المطلوب من مسار file. إذا استخدمت Supabase Storage أو GitHub Pages، ارفع المجلدات والملفات مع المحافظة على نفس البنية. اجعل مسارات الملفات نسبية كما في index.json أو كوّن الرابط العام الكامل حسب رابط الاستضافة.

التحقق: تم فحص ملفات JSON والتأكد من أن تجميع محتوى المقدمة ثم محتوى الأبواب الستة والثلاثين يعيد النص الأصلي بعد فك الترميز دون فقد أي محرف نصي.
